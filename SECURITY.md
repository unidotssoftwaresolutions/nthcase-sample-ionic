# Reporting a security problem

Please do not open a public issue for a vulnerability.

Report it privately, either through GitHub's private vulnerability reporting (the "Report a vulnerability" button on
this repository's Security tab) or by e-mail to security@nthcase.com. Tell us what you found and how to reproduce it.
We will acknowledge your report within 3 working days.

Mossgrove makes no network requests and holds no real data: its account, items and orders are fictional and live
in memory. Releases are **debug builds** on purpose, for testing: a debug-signed Android `.apk` and an unsigned iOS
Simulator `.app`, both with web-view inspection on. Do not install them on a phone you use for anything else. We
support the latest release only.
